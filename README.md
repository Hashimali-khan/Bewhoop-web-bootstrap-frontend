# Bewhoop Frontend

This repository contains the frontend code for the Bewhoop platform, consisting of two main flows:

1. Hoster Flow - For event hosts to manage their events
2. Vendor Flow - For vendors to manage their services

## Project Structure

- `hoster-flow/` - Contains all files related to the event host interface
- `vendor-flow/` - Contains all files related to the vendor interface

## Setup

1. Clone the repository
2. Open the project in your preferred code editor
3. No build step required - files can be served directly

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.2
- JavaScript
